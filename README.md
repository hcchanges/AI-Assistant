# 电子宠物（团子）

一个跑在 Windows 桌面上的中文 AI 宠物。桌面上浮着一个小宠物，它看着你在干什么、记你的事、
主动跟你搭话；也能在微信里帮你**起草**一条回复（只出草稿，发不发、发什么，你自己定）。

> 公开版说明：内部开发版里的「工作模块」（部门流转图 + 两条联网工作卡片）**没有随本仓发布**。
> 菜单里那一项写着「🔒 工作模块（待解锁）」，点进去是一块占位页，需要内部授权版才有内容。

## 它能做什么

| 模块 | 做什么 |
|---|---|
| 桌宠本体 | 透明置顶的小宠物：待机 / 走动 / 睡觉 / 专注等姿态，右键菜单四条（工作 / 生活 / 设置 / 退出），托盘同时驻一个 |
| 聊天陪伴 | 一个对话气泡。它会记你说过的事（本地长期记忆），按你的情绪与性格回话；性格可切（傲娇 / 温柔…） |
| 卡片系统 | 「生活广场」里一张张卡：出行、减脂、餐饮…每张卡有详情页、打卡、上半建议区 + 下半工具区，卡上还能自己长小部件、自己拖布局 |
| 社交帮回 | 微信在聊天页时，读屏认出对方说了什么，生成 2~3 条**草稿**给人挑；点「复制回复」才写剪贴板。**它不发消息、不模拟按键** |
| 屏幕感知 | 本机 OCR 认字幕与窗口内容，据此判断你在网课 / 游戏 / 看片，切对应的陪伴方式；可整条关掉 |
| 情感记忆 | 独立的本地加密库（AES），存关系状态、情绪快照、重大事件——密钥在你自己的机器上，不在仓里 |
| 专注 / 番茄钟 | 手动番茄钟 + 「前台是工作类应用就自动起表」；专注时宠物安静陪着 |
| 活动统计 | 前台应用采样，久坐提醒、分心提醒（都可关） |
| 抓屏笔记 / 知识库 | 只在网课·工作·创作类软件前台时抓屏认字，攒成笔记问你要不要收；本机知识库可以喂自己的文档 |
| 语音 | 语音合成（它出声）与语音输入（本地 whisper，可关） |

## 跑起来

**环境**：Windows 11 + Python 3.12（开发环境是 3.12，3.11+ 应也可以）。纯本地程序，除了你自己配的
大模型服务，不往外发东西。

```bat
git clone <本仓地址> 电子宠物
cd 电子宠物
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**1. 先下向量模型**（本地长期记忆要用，不下起不来）：

```bat
.venv\Scripts\python.exe tools\fetch_embedding_model.py
```

**2. 配一把模型 Key**（二选一，都不会落成明文）：

```bat
:: 方式一：环境变量（llm.providers.deepseek.api_key_ref = llm_deepseek → DEEPSEEK_API_KEY）
set DEEPSEEK_API_KEY=sk-你的key
```

方式二：起程序后在「设置」里填，Key 进 Windows 凭据管理器。

**3. 起**

```bat
.venv\Scripts\python.exe main.py
```

配置都在 `config.yaml`（模型供应商、宠物名字与性格、屏幕感知开关、番茄钟、免打扰时段…）。
运行期数据默认放在本项目的 `data/` 下（`app.data_dir` 留空即如此，也可以改成别的绝对路径）。

## 测试

```bat
.venv\Scripts\python.exe tests\run_all.py
```

每个测试模块在独立子进程里跑，配置、数据库、向量库、日志全部落在临时沙箱里，不碰你机器上的真数据。
单跑一个模块：`python tests\test_social.py`。

## 数据说明

本项目以 AI 聊天陪伴为核心入口，旨在通过对话理解你的个人偏好与上下文，为你生成更贴合的辅助功能。对话过程中，本项目会在本地记录必要信息以支撑个性化功能。这些信息仅用于为你提供服务，不会上传、转交或用于任何其他目的。若你对个人数据极为敏感，请谨慎评估后再使用。

## 几条边界（写死在代码里的）

- **不模拟按键、不碰剪贴板**：社交帮回只出草稿，「复制回复」是唯一一处写剪贴板，而且是你亲手点的。
- **截图不出本机**：OCR 与画面情绪都在本地跑；只有你显式把场景判定切成「云端」那一档，才会往外发。
- **密钥不进仓**：走环境变量或系统凭据管理器，`config.yaml` 里只有凭据名。
- 免打扰时段、各模块开关都在设置页，随时能关。

## 目录

```
core/        装配、配置、事件总线、后台任务
pet/         桌宠本体：窗口、皮肤、姿态、性格
brain/       大模型：链、提示词模板、联网检索
life/        生活侧：cards 卡片 / dialog 对话 / mind 知识库与情感记忆 / profile 画像 /
             psych 心理陪伴 / screen 屏幕感知与社交帮回 / voice 语音
memory/      长期记忆：向量库、提炼、检索
focus/       番茄钟与专注态
monitor/     前台应用与活动采样
ui/          界面：气泡、面板、卡片、设置、皮肤
scheduler/   提醒与定时
data/        数据模型与 DAO（不含运行期数据）
tests/       测试（每条用例都在独立沙箱里跑）
tools/       一次性脚本：下向量模型、备皮肤、回填时间…
work/        工作模块（公开版：空壳占位，见上）
```
