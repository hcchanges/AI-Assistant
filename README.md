# 天渌 Tianlu · 本地优先的 AI 个人助理框架

> 一个运行在桌面的 AI 个人助理 demo：长期记忆图谱 + 关系状态机 + 跨应用上下文 + 工作模块。
> 本项目为**个人学习作品**，用于演示本地 AI 助理的架构设计与工程实现。

## ✨ 核心特性

- **长期记忆系统**：通过“生活卡”沉淀用户特质，用得越久越懂你
- **关系阶段调速状态机**：针对亲子 / 情侣 / 父母 / 亲友等不同关系自动调整交互策略
- **双卡协同**：用户卡 + 对象卡双向画像，生成贴合语境的回复建议
- **跨应用上下文中枢**：统一聚合多来源信息，而非孤立处理单条消息
- **工作模块**：面向工作场景的助理能力（日程 / 任务 / 信息整理，按实际功能填充）
- **本地优先 & 隐私安全**：OCR 与数据存储可本地化，敏感信息不出本机

## 📁 目录结构

~~~
AI-Assistant/
├── brain/           # 能力链与 LLM 接入（意图 / 主动 / 陪伴…）
├── core/            # 上下文中枢与调度
├── data/            # 数据模型与 DAO（不含运行期数据）
├── focus/           # 专注 / 番茄钟
├── life/            # 生活卡与情感记忆
│   ├── cards/       # 双卡协同生成
│   ├── mind/        # 关系状态机
│   └── screen/      # 本地屏幕识别（OCR）
├── memory/          # 长期记忆
├── monitor/         # 前台应用监控
├── pet/             # 桌宠本体
├── scheduler/       # 提醒与定时
├── tests/           # 测试（每条用例在独立沙箱里跑）
├── tools/           # 一次性脚本（下向量模型等）
├── ui/              # 界面
├── work/            # 工作场景模块（公开版：占位）
└── config.yaml      # 配置（模型供应商 / 宠物 / 屏幕感知…）
~~~

关系状态机在 `life/mind`，屏幕识别（OCR）在 `life/screen`，
双卡协同在 `life/cards`，配置是仓库根下的 `config.yaml`。

## 🚀 快速开始

~~~bash
git clone https://github.com/hcchanges/AI-Assistant.git
cd AI-Assistant
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python tools\fetch_embedding_model.py
python main.py
~~~
